## 5. Воспроизводимость и ограничения

Команды запускались из каталога app:

```powershell
gosec ./...
govulncheck ./...
govulncheck -show verbose ./...
```

Последняя команда рекомендована для детализации, её результат ещё не предоставлен. Govulncheck выполнялся с Go 1.27.4, тогда как сборочный образ использует Go 1.22; необходим отдельный анализ фактического бинарника/версии сборки. Список 21 уязвимости по идентификаторам пока не разобран.

Исходный JSON Gosec был выведен в терминал, но наличие файла не подтверждено. JSON Govulncheck сохранён локально, размер 697147 байт. Сырые отчёты в этот репозиторий не загружены: требуется проверить их на секреты и персональные данные. Не публикуются учётные данные, ключи, эксплуатационные payload и внутренние адреса.
