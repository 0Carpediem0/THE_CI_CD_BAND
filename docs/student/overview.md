# Office Wallet — краткое описание

Корпоративный кошелёк сотрудников: баланс, переводы, магазин канцтоваров, чаевые, уведомления о платежах.

## Доступ

После `docker compose up` (см. корневой README):

| Сервис | URL |
|--------|-----|
| Приложение | http://localhost:18081 |
| Почта (Mailpit) | http://localhost:18025 |

Учётки для практики — у преподавателя (`docs/instructor/wallet.md`).

## Что посмотреть в UI

- Главная: баланс и быстрые действия
- Магазин / корзина / заказы
- Переводы и история операций
- Чаевые
- Настройки уведомлений о платеже
- Сброс пароля (письмо в Mailpit)
