== 5. OW-04: отмена чужого заказа: деньги идут его владельцу ==
    · Отмена заказа: проверка владельца стоит только на показе страницы, на самом
    · действии её нет (handlers_shop.go:304-329). Отменяет заказ кто угодно, а
    · деньги возвращаются на счёт владельца — учёт и выдача рассинхронизируются.
    → SQL SELECT id FROM orders WHERE user_id<>1 AND status IN ('paid','delivered') ORDER BY id LIMIT 1
    ← psql (пусто)
    · чужого непогашенного заказа не осталось — создаём его напрямую в базе
    · (доступ к БД у нас из docker-compose.yml, пароль wallet/wallet):
    → INSERT INTO orders (user_id, status, total_kop, ...) VALUES (2, 'paid', 45000, ...)
    → SQL INSERT INTO orders (user_id, status, total_kop, lines_json, item_comment) VALUES (2,'paid',45000,'[]','создан для проверки IDOR') RETURNING id
    ← psql 220
    INSERT 0 1
    ← psql: заказ #220 создан
    → SQL SELECT user_id FROM orders WHERE id=220
    ← psql 2
    → SQL SELECT balance_kop FROM users WHERE id=2
    ← psql 922300
    → SQL SELECT id||' '||status FROM orders WHERE id=220;
    ← psql 220 paid
    ┌─ АРТЕФАКТ · OW-04 · чужой заказ до атаки
    │ заказ #220, владелец user_id=2, статус=220 paid
    │ баланс владельца до: 922300 коп
    └─
    → GET /orders/220  (просмотр чужого заказа — проверки владельца нет)
