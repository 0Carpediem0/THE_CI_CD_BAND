== 4. OW-05: возврат: печатаем и уводим деньги ==
    · Возврат считается как refund = total × qty, а qty не ограничен ни количеством
    · в заказе, ни суммой, ни знаком (handlers_shop.go:350-363): qty=100 печатает
    · сотню стоимости заказа, qty=-1 уводит деньги — то, и другое проводится,
    · при отрицательном только пишется строка в anomaly_log, никто не реагирует.
    → SQL DELETE FROM cart_items WHERE user_id=1
    ← psql DELETE 0
    → POST /cart/add  product_id=1 (товар за 450₽)

    · заказ #218 оформлен (45000 коп), делаем возврат с qty=100:

    ← HTTP 302 redirect=http://localhost:18081/orders/218  <!DOCTYPE html> <html lang="ru"> <head>   <meta charset="utf-8">   <meta name="viewport" content="width=device-width, initial-scale=1">   <title>Заказ · Office Wallet</title>   <link rel="preconnect" href="https://fonts.googleapis.com">   ...
    → SQL SELECT balance_kop FROM users WHERE login='ivanov';
    ← psql 199143300
    → SQL SELECT id||'|'||status||'|'||total_kop FROM orders WHERE id=218
    ← psql 218|returned|45000

    │ заказ после возврата: 218|returned|45000
    └─
