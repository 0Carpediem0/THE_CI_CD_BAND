== 10. OW-11: ложный успех корзины и неактивный товар ==
    · cartAdd не проверяет ни существование товара, ни его флаг active
    · (handlers_shop.go:123-135), ошибку FK он молча проглатывает и всё равно
    · пишет flash «Добавлено в корзину». Дальше JOIN в loadCart отбрасывает
    · несуществующие строки — товар исчезает из корзины, а пользователь уверен,
    · что добавил. Неактивный товар, наоборот, в корзину попадает и покупается:
    → SQL DELETE FROM cart_items WHERE user_id=1
    ← psql DELETE 0
    → POST /cart/add  product_id=999 (нет в каталоге)

    → SQL SELECT count(*) FROM cart_items WHERE user_id=1;
    ← psql 0
    → GET /cart  (что реально в корзине)
    ← HTTP 200  <!DOCTYPE html> <html lang="ru"> <head>   <meta charset="utf-8">   <meta name="viewport" content="width=device-width, initial-scale=1">   <title>Корзина · Office Wallet</title>   <link rel="preconnect" href="https://fonts.googleapis.com"> ...
